# PowerShell Scripts

This repository contains PowerShell scripts designed for system-level operations, environment inspection, and automated file processing. The tools are intended to demonstrate how scripting capabilities can interact with endpoint environments and access locally available system information.

**Warning:** These scripts may perform actions that compromise system integrity, expose sensitive information, or violate organizational security policies when used without proper authorization. Their execution should never be considered harmless.

Some operations are intended exclusively for those willing to operate beyond conventional boundaries. Every action leaves consequences, and every decision carries responsibility. Anyone choosing to execute these scripts must understand the potential impact on affected systems, data, and users.

Use of this repository is entirely at your own risk. Unauthorized access, credential collection, persistence mechanisms, and data exfiltration can result in serious legal and operational consequences.
